# Навигация на публичном сайте RunwayTrans

На первом открытии некоторых страниц Next.js в режиме разработки компилировал маршруты и периодически возвращал HTTP 500 с ошибками Webpack. Публичный Nginx обслуживает сайт через предварительно собранный Next.js. Переменная `RUNWAY_NEXT_DIST_DIR` позволяет собрать следующую версию в отдельном каталоге `.next-runtime/` и проверить её на свободном порту до переключения прокси.

Ссылки в шапке сразу включают язык текущей страницы. Страницы, которые определяют язык и режим предпросмотра из запроса, рендерятся по запросу. Кеши Payload продолжают учитывать язык.

Перед переключением проверять заголовки страниц, запросы из меню и ресурсы через публичный HTTPS. Для отсутствующего документа ожидается HTTP 404. При смене порта синхронизировать конфигурации временного прокси и основного Nginx. Пока общий Nginx обслуживает запросы старым рабочим процессом, переключение происходит через временный прокси. Для отката вернуть его предыдущий upstream и перечитать конфигурацию.
