# Футер RunwayTrans по макету главной

Футер на всех языковых маршрутах использует общий логотип, каталог услуг, контакты и шесть иконок из макета. Лесной блок шириной на весь экран имеет минимальную высоту 300 px. Контент ограничен шириной 1440 px с полями 20 px. На узком экране колонки идут друг под другом, а иконки могут переноситься. [Макет Zeplin](https://app.zeplin.io/project/69dd18ef2b48ae869328c46c/screen/69dd1941fa87a8e23f206a29)

Исходный слой леса доступен только в составе экспорта экрана с надписями. Для сайта реконструирована панорама по этому экспорту. Она сохранена в WebP 2160 × 540 с цветовой коррекцией в CSS. Совпадение с исходным снимком ограничено доступным референсом.

Адрес, телефон и почта взяты из макетов главной и контактов. Страница контактов использует те же значения по умолчанию, пока в глобале Payload нет сохранённых контактов. Реквизиты открываются по якорю на странице контактов. Иконки соцсетей имеют доступные подписи. Рабочие ссылки можно добавить после получения подтверждённых URL.

Существующий переключатель темы и заполненные ссылки локализованного глобала Payload размещены в отдельной полосе под лесным блоком. Полоса сохраняет функциональность при пустом списке ссылок. Схема и запросы Payload остаются прежними.

Проверка включает компоновку при 1200 и 1397 px, переносы на узком экране, читаемость в обеих темах, фокус и раскрытие выбора темы, переход к реквизитам и CMS-ссылки при заполненном глобале.
