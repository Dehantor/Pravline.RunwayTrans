# Навигация к кейсам и отзывам

«Кейсы» всегда доступны в меню по маршруту `/{locale}/cases`. «Отзывы» открывают `/{locale}/reviews`.

Используем существующий маршрут CMS и его правила доступа. Опубликованная в коллекции «Страницы» запись со slug `cases` задаёт содержимое раздела. Если записи или блоков содержимого нет, маршрут показывает локализованный баннер о подготовке страницы. Этот же баннер показывается в «Отзывах» без опубликованных материалов. Шапка загружает ссылки из локализованной навигации без проверки CMS.

Проверка охватывает доступность маршрута при отсутствии публикации, приоритет опубликованной страницы, возврат к баннеру после снятия публикации и отсутствие доступа посетителей к черновику. Обе ссылки открывают свои страницы с языковым префиксом. Выделение активного пункта проверяется отдельно на каждом маршруте.
