# Навигация к кейсам и отзывам

«Кейсы» всегда доступны в меню по маршруту `/{locale}/cases`. «Отзывы» открывают `/{locale}/reviews`.

Используем существующий маршрут CMS и его правила доступа. Опубликованная в коллекции «Страницы» запись со slug `cases` задаёт содержимое раздела. В её отсутствие маршрут показывает локализованные примеры из «Географии». При снятии публикации снова отображаются примеры. Шапка загружает ссылку из локализованной навигации без проверки CMS.

Проверка охватывает доступность маршрута при отсутствии публикации, приоритет опубликованной страницы, возврат к примерам после снятия и отсутствие доступа посетителей к черновику. Обе ссылки открывают свои страницы с языковым префиксом. Выделение активного пункта проверяется отдельно на каждом маршруте.
