# Адреса для поисковых систем

До изменения индекс ссылался на карту, в которой были только адреса поиска и архива публикаций без языкового префикса. Оба адреса перенаправляли поискового робота. Сборка также перезаписывала отслеживаемые файлы в `public` значением из локальной среды.

`robots.txt` и три XML-маршрута генерирует приложение. Общий источник адресов принимает HTTPS origin из `NEXT_PUBLIC_SERVER_URL` и использует `https://rwt.ru`, если настройка отсутствует или указывает на локальный HTTP. Индекс объявляет карту публикаций, когда в ней есть записи. Пустая карта публикаций доступна по прежнему адресу.

Карта содержит конечные языковые адреса главной и содержательных разделов. Казахская страница контактов пока использует русское содержимое. Партнёры и отзывы исключены до публикации содержимого и пересмотра списка разделов. Вакансии представлены страницей списка, на которой уже показаны полные объявления. Служебный поиск, альтернативный адрес главной и шаблонный архив публикаций исключены. Адрес кейсов включается при наличии встроенных примеров или опубликованной локализованной страницы. В релизе с примерами кейсы индексируются, а локальная версия с заглушкой ждёт содержимого.

Для страниц и публикаций CMS используются анонимные права, статус «Опубликовано» и содержимое выбранной локали. Карта исключает коллизии с адресами приложения и проверяет источники редиректов по свежим данным и по кэшу, который использует рендерер. Данные выбираются с устойчивой сортировкой по идентификатору страницами по 50 записей. В памяти сохраняются готовые записи карты, а не содержимое всех страниц. Карты строятся при запросе, чтобы учитывать изменения публикаций.

Критерий проверки публикации — корректный XML и прямой HTTP 200 для каждого конечного HTTPS-адреса в индексе и дочерних картах. Служебные и пустые страницы остаются вне опубликованных карт.
