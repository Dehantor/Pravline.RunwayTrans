# Три посадочные страницы услуг

Для первых страниц выбраны три существующие позиции каталога: доставка гусеничными болотоходами «Витязь», перевозки по зимникам и доставка колёсными вездеходами. Они описывают разные условия заказа. Выбор основан на номенклатуре компании; количественную оценку спроса можно провести по поисковым запросам после публикации.

Адреса используют существующие slug записей Payload. При построении страницы, ссылок каталога, карты сайта и языковых альтернатив проверяется наличие опубликованной записи и локализованных заголовка и резюме без языковой подстановки. Число выбираемых записей ограничено тремя. Описание условий перевозки, параметров расчёта и маршрута хранится в типизированном справочнике на пяти языках. Тарифы, сроки и подтверждение доступности маршрута требуют индивидуального расчёта.

Ссылка ведёт к форме консультации на главной во всех локалях, включая режим без ссылки на политику.

Проверка охватывает три ссылки из каталога, уникальные заголовки страниц, канонические адреса и взаимные языковые ссылки, наличие доступных адресов в карте сайта, переход к запросу расчёта и ответ 404 для неизвестной, неопубликованной или непереведённой услуги.
