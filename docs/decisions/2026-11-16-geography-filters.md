# Фильтры карты перевозок

На странице `/ru/geografiya` кнопки периода, региона и типа груза были статическими, а переключатели транспорта были нарисованы без интерактивных элементов. При первой загрузке Leaflet отрисовка маршрутов могла начаться до создания слоя.

Серверная страница продолжает получать небольшой редакционный список перевозок из глобального блока Payload с локализованными запасными данными. Состояние фильтров принадлежит общему клиентскому компоненту карты и списка. Одна отфильтрованная выборка определяет строки и линии на карте, а Leaflet обновляет выделенный слой после завершения инициализации. Применение фильтров обходится без запросов к CMS. Для выпадающих полей используется `react-select` 5.10.2 с лицензией MIT и поддержкой React 19. [Журнал React Select](https://github.com/JedWatson/react-select/blob/master/packages/react-select/CHANGELOG.md)

Периоды берутся из фактических значений поля «Период». Исходный выбор охватывает все периоды и оба вида транспорта. Вид транспорта определяется по явной формулировке в описании или по идентификатору известной перевозки. Записи с неуказанным или неоднозначным видом транспорта видны с обоими включёнными переключателями. Фильтр региона предлагает семь опубликованных направлений. Красноярский край сопоставляется с двумя известными маршрутами по их идентификатору или сочетанию топонимов. Для произвольных записей без достоверного региона действует выбор «Все регионы». Текущая схема CMS хранит описание, период, маршрут, длительность, цвет и точки. Фильтр типа груза отображает локализованную причину недоступности, поскольку отдельного поля для этой характеристики нет. Добавление поддерживаемой редакторами классификации требует расширения схемы. Текущий контракт Payload и доступ к странице сохраняются.

Фильтрация выполняет проход по уже загруженным редакционным записям. Отрисовка слоя дополнительно зависит от числа точек на видимых маршрутах. Если блок начнут использовать как архив перевозок с десятками страниц, измерить размер ответа и задержку фильтрации и перейти к структурированным полям, серверным фильтрам и порционной загрузке списка. Для карты отдельно определить, какие маршруты и точки нужны в текущем масштабе. Нагрузочная готовность архива этим изменением не проверяется.

## Критерии проверки

- Сразу после прямого открытия страницы видны оба известных маршрута при доступном наборе данных.
- Выбор одного периода, нескольких условий или региона без перевозок согласованно меняет список и линии. Очистка условий восстанавливает исходный набор, а пустая выборка сопровождается сообщением. При быстрых последовательных переключениях итоговые линии остаются видимыми после изменения масштаба.
- Переключатели работают мышью и клавиатурой. Выбор региона и периода, закрытие меню и подсказка о типе груза доступны на узком экране и в обеих поддерживаемых темах. Элементы карты остаются доступны после закрытия меню.
- Подписи, состояния и сообщения доступны во всех языках маршрута. Применение фильтров не отправляет запросы к CMS.
